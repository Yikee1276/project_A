## 第 1 课：模板基础

### 1. 为什么需要模板
在 C 语言中，如果我们需要对不同类型（如 `int`, `double`）执行相同的逻辑（比如 `swap` 或求最大值），通常需要写多个函数，或者用宏、`void*`。这不仅代码冗余，而且缺乏类型安全检查。
**模板（template）** 是 C++ 的解决方案：把“类型”本身变成参数，写一份代码，编译器按实际使用的类型生成对应的版本（编译期展开）。

### 2. 函数模板与推导
```cpp
template <typename T> // 模板头，T 是类型占位符
T my_max(const T& a, const T& b) {
    return (a > b) ? a : b;
}
```
- **调用**：`my_max(1, 2)`。编译器会根据实参自动推导出 `T` 是 `int`。
- **显式指定**：`my_max<int>(1, 2)`。
- **实例化**：模板本身不生成机器码，只有在被调用时，编译器才“隐式实例化”出具体版本的代码。

### 3. 类模板与必须显式指定类型
```cpp
template <typename T>
class Box {
public:
    Box() : value_{} {}
    explicit Box(const T& v) : value_(v) {}
    T get() const { return value_; }
    void set(const T& v) { value_ = v; }
private:
    T value_;
};
```
- **使用**：`Box<int> b(42);`。与函数模板不同，类模板在创建对象时**不能**自动推导，必须显式写出 `<类型>`。
- `Box<int>` 和 `Box<double>` 在编译器看来是两个完全独立、毫不相干的类。

### 4. 类外定义类模板成员函数
如果成员函数写在类外，必须**重复模板头**，且类名后要带上 `<T>`：
```cpp
template <typename T>
T Box<T>::get() const {
    return value_;
}
```

### 5. 花括号 `{}` 与圆括号 `()` 初始化的区别
在成员初始化列表中：
- `value_{}`：**空花括号代表值初始化**，等同于将成员设为“零值”或调用默认构造函数。
- `value_(v)`：**圆括号代表直接初始化**，用传入的 `v` 来构造成员。
**为什么泛型中带参推荐用 `()`？** 因为如果 `T` 碰巧是带有 `initializer_list` 构造函数的类型，`value_{v}` 可能会被编译器“自作聪明”地解析为调用列表初始化，导致语义跑偏；而 `(v)` 老实本分，只寻找拷贝或普通构造函数，最稳妥。

## 第 2 课：类模板进阶与迭代器概念

### 1. `using` 类型别名
```cpp
using value_type = T;
using pointer = T*;
```
- C 语言中常用 `typedef`，C++11 引入 `using`，语法更直观。
- 在泛型编程（STL标准）中，容器必须暴露 `value_type` 这样的别名，让外部算法知道容器里装的是什么。

### 2. 什么是迭代器
迭代器（Iterator）是一种**行为像指针的对象**。它提供了一套统一的方式，无论底层是数组还是链表，都可以用相同的方式遍历（`*` 取值，`++` 移动，`!=` 比较）。
对于连续内存的容器（如我们的 `MyArray`），**原生指针 `T*` 天生就是最完美的迭代器**。

### 3. `begin()` 与 `end()` 的左闭右开法则
- `begin()` 返回指向第一个元素的迭代器。
- `end()` 返回指向**最后一个元素的下一个位置**（尾后指针）的迭代器。
- **好处**：判断循环结束非常方便，只需判断 `it != end()`；且当容器为空时，`begin() == end()` 直接成立，无需特判。

### 4. 范围 for 循环的底层逻辑
```cpp
for (auto x : arr) { ... }
```
编译器会将其翻译为：
```cpp
auto __begin = arr.begin();
auto __end = arr.end();
for (; __begin != __end; ++__begin) {
    auto x = *__begin;
    // ...
}
```
**只要你的类实现了 `begin()` 和 `end()`，返回的对象支持 `!=`、`++`、`*`，就可以用范围 for。**

### 5. `auto` 关键字
- C++11 引入的**编译期类型推导**。不是动态类型，没有运行期性能损耗。
- 必须初始化。
- **范围 for 遍历推荐写法**：`for (const auto& x : arr)`。不加 `&` 会导致每次循环发生拷贝；不加 `const` 则可能被意外修改。`const auto&` 兼顾零拷贝与安全。

### 6. 为什么函数模板参数推荐用 `const T&`
- **不用 `T`（传值）**：如果 `T` 是很大的对象，每次调用都会发生深拷贝，性能极差。
- **不用 `T&`（普通引用）**：内部可能意外修改外部变量；且无法接收字面量或临时对象。
- **用 `const T&`**：只传地址（零拷贝），保证只读（安全），且能绑定左值和右值（通用性极强）。

### 7. 非类型模板参数 `int N`
```cpp
template <typename T, int N>
class MyArray {
    T data_[N];
};
```
- `T` 代表类型，`N` 代表**具体的整数值**。
- `N` 必须在**编译期**确定（如 `MyArray<int, 5>`）。编译器在编译期就能算好对象占用的内存大小，避免了 C 语言中变量无法作为数组长度定义的尴尬。

## 用户提问与对话概括

**Q1：为什么 Box 类的代码中，一行用花括号 `value_{}`，一行用圆括号 `value_(v)`？**
**对话概括**：空花括号 `{}` 用于默认的“值初始化”，将变量置零或调默认构造；圆括号 `(v)` 表示用特定值直接初始化。在泛型模板中，带参时用 `()` 是为了防止 `T` 如果碰巧是带 `initializer_list` 的类型时，`{}` 被编译器误判为列表初始化，导致语义偏移。用 `()` 意图最纯粹、最安全。

**Q2：以 vector 为例，用 `{}` 和 `()` 会如何调用构造函数？（经用户提醒后已声明后续不再提前涉及未讲知识）**
**对话概括**：在类型完全匹配时，两者通常都调用拷贝构造。但如果传入的是内置类型，`(v)` 会调用参数为个数的构造（如创建 N 个元素），而 `{v}` 会优先匹配 `initializer_list` 构造（创建 1 个元素）。这说明花括号在泛型中有“抢跑”的风险，圆括号更稳妥。

**Q3：`auto` 是什么？**
**对话概括**：`auto` 是 C++11 的编译期类型推导关键字。它要求必须在定义时初始化。在范围 for 循环中，推荐使用 `const auto&`，既避免了传值拷贝的性能损耗，又保证了不会修改原数据。

**Q4：为什么 `template <typename T>` 后面直接跟 `#endif` 会爆红？**
**对话概括**：`template <typename T>` 只是声明头，不能单独存在，后面必须紧紧跟着函数或类的定义。如果后面直接是文件结束符，编译器等待类名或函数名落空，就会报语法错误。

**Q5：函数模板为什么参数要引用（`const T&`）？**
**对话概括**：在泛型中，如果按值传参（`T`），遇到大对象（比如上万字节的结构体）会发生严重的拷贝开销；如果只写引用（`T&`），不仅内部可能误改原值，而且无法接收临时变量。`const T&` 完美兼顾了零拷贝（只传地址）、绝对安全（防误改）以及通用性（左右值皆可接）。

**Q6：参数中的 `int N` 是什么意思？**
**对话概括**：这叫“非类型模板参数”，表示传入的不是一个类型，而是一个具体的数值。它必须在编译期确定。通过在模板参数里引入 `int N`，我们就能把数组的长度变成一个参数，从而让 `MyArray<T, N>` 成为可以动态指定大小的“模具”，这比 C 语言的宏和写死大小灵活得多。
